# ZLF Music — Miku Edition

## Cara jalanin
1. `npm install`
2. `npm run dev`
3. Buka http://localhost:5173

## Nambahin sticker Miku kamu
Lihat `public/assets/README.txt`.

## Struktur
- `src/App.jsx` — semua UI (Home + My Library), tema warna, filter, search, animasi
- `index.html` — Tailwind CDN + Google Fonts
- `public/assets/` — taro sticker PNG di sini
